# Paradise Nursery

A responsive React and Vite e-commerce application for browsing and purchasing houseplants at Paradise Nursery.

## Features

- Plant catalog and product details
- Persistent shopping cart using Redux Toolkit and localStorage
- Add, increase, decrease, and remove cart items
- Dynamic item subtotals and order total
- Responsive desktop and mobile layouts
- Empty cart and order confirmation states

## Run locally

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```
